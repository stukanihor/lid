# Leben in Deutschland — тренажёр

### ▶ Открыть: **https://stukanihor.github.io/lid/**

Подготовка к тесту «Leben in Deutschland» / Einbürgerungstest: все **460 вопросов**
официального каталога — 300 общих и по 10 для каждой из 16 федеральных земель.

## Что внутри

- **Карточки** — вопрос по-немецки, перевод по кнопке, разъяснение «почему так» к каждому ответу.
- **Экзамен** — как настоящий: 33 вопроса (30 общих + 3 по вашей земле), 60 минут, порог 17 правильных.
  После экзамена — разбор всех вопросов с пометкой верно/неверно и история попыток.
- **Прогресс** — шанс сдать прямо сейчас, покрытие каталога, интервальное повторение, темп и серия дней.
- **PDF со всеми ответами** — вкладка «Прогресс» → «Все ответы» → «Скачать PDF»: ~80 страниц A4
  с вопросами, переводом, правильными ответами, разъяснениями и картинками. Можно распечатать.
- **14 языков** интерфейса и переводов: русский, українська, English, Deutsch, español, italiano,
  polski, română, български, srpski, slovenščina, türkçe, العربية, فارسی.
- **Озвучка** вопросов по-немецки.

## Как пользоваться

1. Откройте ссылку выше в любом браузере — регистрации и установки не нужно.
2. Вверху выберите свою **федеральную землю** и **язык**.
3. На iPhone/Android: «Поделиться» → «На экран „Домой“» — запускается как приложение.

Прогресс хранится только в вашем браузере: у каждого он свой, никуда не отправляется,
сервера у проекта нет.

## Технически

Весь тренажёр — один файл `index.html` (~6 МБ): вопросы, переводы, картинки и шрифты для PDF
внутри него, внешних запросов страница не делает и работает без интернета после первой загрузки.

Вопросы — официальный каталог Einbürgerungstest / «Leben in Deutschland» (BAMF).
